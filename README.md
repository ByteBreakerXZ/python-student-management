This project is a simple command-line student management system built with Python.

The program allows users to add students and their grades, view the list of students, calculate a student's average grade, find the student or students with the highest average, and display students whose average grade is 15 or higher.

The main purpose of this project was to practice fundamental Python concepts and improve problem-solving skills through building a small practical application.

Features:

Add students and their grades
Display the list of students
Calculate a student's average grade
Find the student or students with the highest average
Display students with an average grade of 15 or higher
Validate user input
Exit the program through the main menu

Python Concepts Used:

Functions
Lists
Dictionaries
for loops
while loops
if / elif / else
return
break and continue
User input and validation
Working with keys() and items()

# Student Management System

A simple student management application built with Python.

## About the Project

This project started as a small command-line Python project that I created to practice the fundamentals of Python, especially:

- Functions
- Loops
- Lists
- Dictionaries
- Conditional statements
- Input validation
- Basic data processing

The core logic of the application is based on my original simple Python project.

For this version, I wanted to improve the project by adding a graphical user interface (GUI).

Since I am still learning GUI development, I used AI to help design and implement the graphical interface.

**I did not write the GUI code myself.**

The purpose of doing this was to explore how AI can be used as a development tool and to turn a simple Python project into a more practical application.

I consider the GUI part of this project a learning experience rather than a skill that I currently claim to have mastered.

## Features

- Add students and their grades
- Validate grades between 0 and 20
- Calculate student averages
- Find the student with the highest average
- Handle multiple students with the same highest average
- Display students in an organized table
- Identify students with an average of 15 or higher
- Dashboard with basic statistics
- Graphical user interface using CustomTkinter

## Who Can Use It?

This application can be useful for **teachers, instructors, tutors, and educational staff** who need a simple way to manage and review students' grades.

For example, a teacher can:

1. Add a student's name
2. Enter their grades
3. Automatically see their average
4. View all students in an organized table
5. Find the highest-performing student
6. Identify students whose average is 15 or higher

This project is intentionally simple and is not intended to replace professional school management systems.

## Technologies

- Python
- CustomTkinter
- Basic Python data structures
